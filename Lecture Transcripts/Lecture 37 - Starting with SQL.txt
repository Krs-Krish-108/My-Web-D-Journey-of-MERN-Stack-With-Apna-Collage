# MySQL and MongoDB Overview

## Summary
### Flow Summary
Speaker 1 ne Delta course ke liye databases ka intro diya: SQL vs NoSQL, tables aur schema, MySQL Workbench setup, aur basic SQL commands (CREATE, DROP, USE, INSERT, SELECT) ka demo.

### Database aur DBMS ki basics
- Database large data ka collection hai; SQL ek language hai jo database se baat karne ke liye use hoti hai, khud database nahi
- Files ke mukable databases: large data storage, security, scalability, aur aasan search/CRUD operations
- Ab tak data.json ya arrays par CRUD kiya, practical life mein ye sab databases ke saath hota hai
- DBMS database ke upar ek layer hai jo operations aur SQL queries deti hai

### SQL vs NoSQL databases
- SQL (relational) databases data tables mein store karte hain; table ko hi relation kehte hain
    - Examples: MySQL, Oracle, PostgreSQL; sab SQL use karte hain, thoda flavor alag
- NoSQL (non-relational) databases ka collection hai jo SQL use nahi karte: documents, key-value, graph
    - Examples: MongoDB, Cassandra, Neo4j; MongoDB MERN/MEAN stack ka M hai
- Course order: pehle MySQL, phir MongoDB; dono independent hain, SQL tables se visualize karna aasan
- Company ki tech stack jaanna interviews mein edge deta hai, jaise Oracle ke liye SQL basics

### Server, databases, tables aur schema
- MySQL ek server hai jis par multiple databases bante hain, har database mein interrelated tables
    - Examples: college (student, teacher), xyz company (employee), Instagram (user)
- Columns table ka design batate hain, jise schema kehte hain
- Row ek entity ka data hoti hai, jise tuple kehte hain

### Installation aur MySQL Workbench
- Do cheezein install karni hain: MySQL server aur MySQL Workbench (Windows aur Mac dono ke liye links diye gaye)
- Workbench mein naya connection banaya (delta connection), password set kiya, test connection kiya; default localhost3306
- sys database internal system data rakhta hai, ise kabhi change nahi karna
- Selected statement ko cursor wale execute option se ek-ek karke run karna prefer karenge

### Basic SQL commands demo
- CREATE DATABASE college aur xyz\_company banaye; DROP DATABASE se xyz\_company delete kiya
- SQL case insensitive hai; commands capital mein, naam small mein likhna prefer, har command ke end mein semicolon
- USE college ke baad CREATE TABLE student: roll\_number int, name varchar(30), age int
- INSERT INTO se Adam (101, 12) aur Bob (102, 14) add kiye, SELECT \* FROM student se dekha; IF NOT EXISTS error ko warning banata hai

# SQL Database Concepts Overview

## Summary
### Flow Summary
Speaker 1 ne MySQL basics padhaye: database aur table commands, data types, constraints, primary/foreign keys, ER diagram, aur INSERT/SELECT. Post table ke liye homework diya.

### Database Commands
- CREATE DATABASE IF NOT EXISTS: database pehle se ho to error nahi, sirf warning aati hai
    - Example: college aur instagram databases banaye
- DROP DATABASE IF EXISTS college se database tabhi delete hota hai jab woh exist kare
- SHOW DATABASES sab databases dikhata hai; mysql, performance schema, information schema internal hain
- SHOW TABLES se pehle USE instagram karna padta hai; abhi tables khaali thi

### Table Commands aur Data Types
- Table commands: CREATE, INSERT, UPDATE, ALTER, TRUNCATE (data khaali), DELETE (poori table)
- CHAR fixed length, VARCHAR variable (dono 0 se 255); VARCHAR prefer kiya kyunki memory waste nahi hoti
    - Bade objects ke liye BLOB
- Number types: INT, TINYINT (-128 se 127), BIGINT, BIT (till 64), FLOAT, DOUBLE; BOOLEAN internally TINYINT hai
    - UNSIGNED TINYINT range 0 se 255 ho jaati hai
    - DATE aur YEAR bhi available
- User table schema: id INT, name VARCHAR(30), email VARCHAR(50), followers INT, following INT

### Constraints aur Keys
- Constraints: NOT NULL (name), UNIQUE (email), DEFAULT (followers 0, salary 25,000), CHECK (age >= 13)
    - CHECK constraint ka naam (jaise age check) optional hai; AND se conditions mix kar sakte hain
- PRIMARY KEY automatically unique aur not null; table mein ek hi, ya columns ka combination (id + name)
- FOREIGN KEY doosri table ki primary key refer karti hai; duplicate, null aur multiple foreign keys allowed
    - Example: student table ka teacher ID, teacher table ki ID refer karta hai

### Post Table aur ER Diagram
- Post table: id INT PRIMARY KEY, content VARCHAR(100), user id FOREIGN KEY REFERENCES user(id)
- MySQL Workbench mein reverse engineer karke ER diagram dekha: primary key chaabi, not null dark blue, FK arrow
- ER ka matlab entity relation; database ki bhasha mein table ko relation kehte hain

### INSERT aur SELECT
- INSERT INTO mein columns aur VALUES ka order same hona zaroori hai; 4 users (jaise Adam) insert kiye
- Constraint errors demo: duplicate ID, name missing, duplicate email, age 10 par CHECK violation
- SELECT columns FROM table; \* ka matlab all; DISTINCT se sirf unique values (ages 14, 15, 16, 17)
